# Бот-модератор для Telegram-чатов

Модерация, автозащита, капча, РП (140+ команд) и 18+ РП (только с согласия адресата), профили, браки, репутация, заметки, ночной режим.
Плюс: экономика и казино, дома/машины/питомцы, отношения, друзья, дети и беременность, ИИ-собеседник на Gemini с ролёвками и отношениями.
Встроенная «будилка» для Render (веб-сервер + самопинг).

## Запуск локально
    pip install -r requirements.txt
    BOT_TOKEN=... OWNER_IDS=ваш_id python main.py

## Деплой на Render
1. Создай бота у @BotFather → получи токен. В BotFather: /setprivacy → Disable (чтобы бот видел все сообщения).
2. Залей папку в GitHub-репозиторий.
3. Render → New → Blueprint (или Web Service) → выбери репозиторий. Файл render.yaml всё настроит.
4. В Environment задай BOT_TOKEN и OWNER_IDS (твой Telegram id, узнать: /id).
5. Будилка включается сама: Render задаёт RENDER_EXTERNAL_URL, бот пингует /health каждые 4 минуты.
   Для надёжности добавь ещё внешний пинг (UptimeRobot) на https://<твой-сервис>.onrender.com/health

## Важно
- Сделай бота админом чата (удаление сообщений, блокировка, закрепление).
- На бесплатном Render диск временный: база (SQLite) сбрасывается при перезапуске/деплое.
  Для сохранности подключи Persistent Disk и поставь DB_PATH=/var/data/bot.db.

## ИИ (Gemini)
1. Получи ключ в Google AI Studio и задай переменную `GEMINI_API_KEY` (на Render — в Environment).
2. Модель меняется переменной `GEMINI_MODEL`, имя ИИ — `AI_NAME`, строгость фильтра Google — `GEMINI_SAFETY`.
3. В личке ИИ отвечает на любой текст; в группе — на «Мия, …», «ии …», «бот …» или ответ на её сообщение.
4. Все сцены только между взрослыми и по согласию; сексуальное насилие и несовершеннолетние исключены в промпте.

## Новые разделы
`/help` → «Экономика», «Семья», «ИИ». Каждый раздел можно выключить в `/settings`.
Беременность идёт в реальном времени (`PREG_HOURS`, по умолчанию 6 ч); рождение объявляется в чате само.

## Самоправка: ИИ меняет себя по просьбе владельца
Только для `OWNER_IDS` и только в личке с ботом. Просто опиши, что поменять:

    /dev стань строже и отвечай короче          — характер/промт (применяется сразу)
    /dev смени имя на Лина                       — имя, модель, температура (сразу)
    /dev добавь команду /кубик, кидает d20       — правка кода: придёт diff и кнопки подтверждения
    /dev on | off    — диалог без префикса      /dev clear — забыть разговор
    /diff  /history  /rollback [id]  /restart  /devreset да
    /prompt — текущие настройки ИИ, /prompt undo — отменить последнюю

Как это работает и чем защищено:
- ИИ получает инструменты: читать файлы, искать по коду, точечно править, создавать файлы, менять настройки (характер `persona`, указания `extra`, имя, модель, температуру).
- Код **не применяется сам**: владелец видит diff-файл и жмёт «Применить» / «Применить и перезапустить». Перед применением Python-файлы проверяются на синтаксис.
- Каждая правка сохраняется в истории; `/rollback` возвращает старую версию.
- **Сторож запуска**: если после правки бот не доработал до «здорового» состояния (45 сек), при следующем старте правка откатывается автоматически, владельцу приходит уведомление.
- Защищены от правки (ИИ может их только читать): `main.py`, `selfedit.py`, `devagent.py`, `handlers/dev.py`. Недоступны совсем: `.env`, базы данных, `data/`, `.git`.
- Жёсткие правила промта (несовершеннолетние, насилие, согласие) остаются в коде и не затираются настройками `persona`/`extra`.
- `SELFEDIT_AUTO=1` — применять правки без подтверждения (по умолчанию выключено, не рекомендуется).

**Про хранение:** правки кода, история и настройки ИИ лежат в `data/selfedit`. Если подключена база Neon (`DATABASE_URL`), эта папка автоматически
копируется в таблицу `selfedit_files` и восстанавливается при старте, так что всё переживает деплой и перезапуск на Render. Без `DATABASE_URL`
на бесплатном Render диск временный, и правки пропадут. Если после деплоя файл в репозитории изменился, старая правка этого файла
пропускается и удаляется (владельцу придёт уведомление). Не отдавай `DATABASE_URL` никому: кто может писать в эту базу, тот может подложить код через `selfedit_files`.

## База данных Neon (PostgreSQL)
По умолчанию бот работает на SQLite (`DB_PATH`). Чтобы данные жили в Neon, задай переменную окружения `DATABASE_URL`, остальное бот сделает сам:
таблицы создадутся при первом запуске, SQLite перестанет использоваться.

1. Зарегистрируйся на https://console.neon.tech → **New Project**. Выбери регион ближе к серверу Render (например, Frankfurt для Render Frankfurt), имя любое. База `neondb` создаётся сразу.
2. На дашборде проекта нажми **Connect**, оставь ветку `main`, роль и базу по умолчанию, включи **Connection pooling** и скопируй строку вида
   `postgresql://user:пароль@ep-xxxx-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require&channel_binding=require` (можно целиком, даже вместе с `psql '...'`).
3. Render → твой сервис → **Environment** → добавь `DATABASE_URL` с этой строкой → сохрани (сервис перезапустится).
   Локально: допиши её в `.env`.
4. В логах должно быть `База данных: PostgreSQL`. Если видишь `SQLite`, переменная не подхватилась.

Нюансы: на Free-плане Neon усыпляет базу после 5 минут простоя (первый запрос после паузы идёт дольше, бот сам повторит его); лимит бесплатного плана 0,5 ГБ и 100 CU-часов вычислений в месяц.
Не пингуй базу «для бодрости»: это сожжёт часы. Данные из старого SQLite в Neon автоматически не переносятся.

## Интернет и фишки
Включаются в `/settings` → «🌐 Интернет» (по умолчанию включено). Отдельного ключа не нужно: поиск делает сам Gemini (Google Search), погода и курсы идут с бесплатных API.

| Что | Как |
|---|---|
| Поиск в интернете | `/search запрос`, `новости [тема]`; в разговоре: «Мия, найди …», «Мия, что нового в …» (отвечает в своём стиле) + ссылки на источники |
| Погода | `погода Москва` (Open-Meteo), потом можно просто `погода` |
| Курсы валют | `курс`, `курс usd`, `курс 100 eur`, `курс 1000 тенге` (ЦБ РФ) |
| Пересказ ссылки | `перескажи https://…` или ответом на сообщение со ссылкой |
| Проверка фактов | ответь `проверь` на сообщение, получишь вердикт и источники |
| Перевод | ответь `переведи` или `переведи на английский` |
| Голосовые | ответь `расшифруй` на голосовое |
| Зрение | фото с подписью «Мия, что тут?» (в личке достаточно фото) или ответ так на чужое фото |
| Пересказ чата | `пересказ`, «что я пропустил»; включает админ в `/settings`. Бот хранит последние 300 сообщений **только в памяти** (не в БД и не на диске), при перезапуске они забываются |

Лимиты: поисковых запросов Gemini не больше `WEB_DAILY_LIMIT` в сутки на весь бот (по умолчанию 300), у каждого человека пауза между запросами. Для режима разработчика (`/dev`) выход в интернет намеренно не добавлен: текст из сети мог бы подсунуть ему команды на правку кода.
