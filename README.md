# Бот-модератор для Telegram-чатов

Модерация, автозащита, капча, РП (140+ команд) и 18+ РП (только с согласия адресата), профили, браки, репутация, заметки, ночной режим.
Плюс: экономика и казино, дома/машины/питомцы, отношения, друзья, дети и беременность, ИИ-собеседник на Gemini с ролёвками и отношениями.
Встроенная «будилка» для Render (веб-сервер + самопинг).

## Запуск локально
    pip install -r requirements.txt
    BOT_TOKEN=... OWNER_IDS=ваш_id python main.py

## Деплой на Render
1. Создай бота у @BotFather → получи токен. В BotFather: /setprivacy → Disable (чтобы бот видел все сообщения).
2. Залей папку в GitHub-репозиторий.
3. Render → New → Blueprint (или Web Service) → выбери репозиторий. Файл render.yaml всё настроит.
4. В Environment задай BOT_TOKEN и OWNER_IDS (твой Telegram id, узнать: /id).
5. Будилка включается сама: Render задаёт RENDER_EXTERNAL_URL, бот пингует /health каждые 4 минуты.
   Для надёжности добавь ещё внешний пинг (UptimeRobot) на https://<твой-сервис>.onrender.com/health

## Важно
- Сделай бота админом чата (удаление сообщений, блокировка, закрепление).
- На бесплатном Render диск временный: база (SQLite) сбрасывается при перезапуске/деплое.
  Для сохранности подключи Persistent Disk и поставь DB_PATH=/var/data/bot.db.

## ИИ (Gemini)
1. Получи ключ в Google AI Studio и задай переменную `GEMINI_API_KEY` (на Render — в Environment).
2. Модель меняется переменной `GEMINI_MODEL`, имя ИИ — `AI_NAME`, строгость фильтра Google — `GEMINI_SAFETY`.
3. В личке ИИ отвечает на любой текст; в группе — на «Мия, …», «ии …», «бот …» или ответ на её сообщение.
4. Все сцены только между взрослыми и по согласию; сексуальное насилие и несовершеннолетние исключены в промпте.

## Новые разделы
`/help` → «Экономика», «Семья», «ИИ». Каждый раздел можно выключить в `/settings`.
Беременность идёт в реальном времени (`PREG_HOURS`, по умолчанию 6 ч); рождение объявляется в чате само.
